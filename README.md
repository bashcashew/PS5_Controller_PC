# Controller
This is a python script that allows for a controller outputs to be intercepted and re-bound to new values. This includes rumbling effects and stores telemetric data to ensure efficient analyses as needed.



### Usage
Please note that the script can be remapped easily to different keypresses and controller buttons.

Just run the .py script in the preferred CLI and should run smoothly and if exit script when done using. 
This was tested only on MacOS and therefore not 100% positive on operability of other Distros and OSs.

Please enjoy! :D
